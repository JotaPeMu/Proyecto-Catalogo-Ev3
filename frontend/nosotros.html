Quiénes Somos

Conectando comunidades gamers con tecnología web moderna en Quilpué

Nuestra Historia

Play The Game Store nació en la Región de Valparaíso como una plataforma tecnológica orientada a reunir en un solo catálogo digital lo mejor del ecosistema gamer: videojuegos, consolas de última generación, periféricos de alto rendimiento, suscripciones y gift cards digitales. Nuestro propósito es brindar a jugadores, estudiantes y entusiastas del gaming un espacio rápido, confiable y estructurado para explorar y gestionar productos gamer.

Desarrollada bajo una arquitectura Full-Stack moderna con PostgreSQL, Express y Bootstrap 5, nuestra plataforma demuestra cómo la integración eficiente entre bases de datos relacionales e interfaces responsivas mejora la experiencia de búsqueda y gestión de catálogos digitales.

🎯 Misión

Facilitar el descubrimiento, filtrado y gestión de videojuegos, consolas, periféricos y servicios digitales mediante una plataforma web ágil, respaldada por bases de datos relacionales robustas y estándares abiertos.

🚀 Visión

Consolidarnos como una tienda y catálogo digital de referencia para entusiastas del mundo gamer y el desarrollo de software en Chile.

🛡️ Valores

  • Integridad y precisión en los datos.
  • Código limpio y buenas prácticas de ingeniería.
  • Diseño accesible, responsivo y centrado en el usuario.

Arquitectura Tecnológica

PostgreSQL Persistencia relacional y consultas INNER JOIN
Node.js + Express API RESTful y servidor estático
Bootstrap 5.3 Diseño responsivo y componentes interactivos
JavaScript ES6+ Consumo asíncrono Fetch API y filtrado dinámico
